# The analysis results in this file have been assembled from the
#
#   Multi-INstrument Burst ARchive (MINBAR) data release 1
#
# comprising analyses of thermonuclear (type-I) X-ray bursts observed by
# the Rossi X-ray Timing Explorer (RXTE), BeppoSAX, and INTEGRAL.
# For the definitive version of the analysis results comprising
# data release 1, download the machine-readable tables available at
#
#   https://doi.org/10.26180/5e4a697d9b8b6
#
# For more information, see the preprint at http://arxiv.org/abs/2003.00685 
# or contact the PI Duncan.Galloway@monash.edu
#
# The MINBAR data has been augmented with bursts observed with:
# - Swift from Bozzo et al. (2010), one of which was also seen by RXTE/PCA;
# - XMM-Newton from Papitto et al. (2010, MNRAS 407, 2575); and
# - Chandra as reported by Falanga et al. (2011)
#
# The fluence for the Swift bursts has been inflated by a factor of
# 1.323 +/- 0.005 based on comparisons with nearby PCA bursts.
#
# Where bursts were observed with multiple instruments, we retain only the most
# accurate measurement
#
# MJD 55086 corresponds to 2009 September 12
#
# This data file has been adapted from the original 17511_bursts.txt by
# addition of the peak burst flux, which will be used to provide
# additional constraints on the distance and burst emission anisotropy via
# beansp. Peak flux for selected Swift bursts has been scaled as for the
# fluence.
#
# This data file has been further augmented with "measured" alpha values,
# utilising integrated persistent flux values arising from the flux model,
# via the burst_table method.
#
# The last comment line before the data gives the column field names, which
# are also described below:
#   time = Burst start time (MJD UT)
#   bfluen = Bolometric fluence (integrated bolometric flux), E_b
#   bfluene = Uncertainty on bolometric fluence
#   bpflux = Bolometric peak flux, F_p
#   bpfluxe = Uncertainty on bolometric peak flux, F_p
#   pre = PRE flag (MINBAR convention); 1=non-PRE, 2=PRE, 3=marginal, -1=no data
#   alpha = Ratio of integrated persistent flux to burst fluence, alpha
#   alphae = Uncertainty on alpha
#   note = Instrument label, reference etc.
#
# Since the bolometric peak flux and fluence is not available for the
# JEM-X bursts (instr flag beginning with IJ), the fluence and peak flux
# for these bursts has been adopted from Falanga et al. (2011, A&A 529,
# A68) for the events common to both lists
#
# For a complete description of the table fields and units, see
#   https://burst.sci.monash.edu/static/html/columns.html
#
